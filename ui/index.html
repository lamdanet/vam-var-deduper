        Downloads

        Sources

        Paste a forum post or a few links — Pixeldrain files and lists, MEGA files and folders, MediaFire, or links straight to a .var or .zip. Every .var they hold is listed, including the ones inside (password-protected) zips, ready to save as download sources — which Scan Dependencies, VAR Details and the Hub then download from.

        Find .var files

        key

        Several links with different passwords? Passwords written in the post ("Password: …") are tried on each protected zip — the one nearest its link first — and the one that opens it is filled in and marked Verified. Otherwise type it in that zip's box and press Check.

        Saved sources

        search

        A new link never replaces the ones already saved for a file. When a download through one fails, the file's other links are tried in turn, and links that have worked before are used first.

        Configuration

        VaM directory
        hard_drive Not configured

        Pick the folder VaM is installed in (the one that contains AddonPackages).

        Every page reads packages from AddonPackages, the folder VaM itself loads. Folders added here are also checked when finding a package's dependencies and when scanning which packages use one before you delete it; each page keeps its own Add folder list for its scans.

        Offload folder
        archive Not configured

        Offload moves packages (and the dependencies you pick) out of AddonPackages into this folder, so VaM stops loading them; Restore moves them back. Unticked, a package keeps the subfolder it had. VAR Packages, Clean Duplicates, Missing Resources, Internalize and the other scans include this folder.

        download

        Where downloaded VARs are saved. Leave blank to save them into AddonPackages; if no VaM directory is set either, you'll be asked to pick a folder the first time you download.

        e.g. qing.hgf1.1 → <downloads>\qing\qing.hgf1.1.var

        Optional power-user features. These touch how the local database is indexed; only enable if you understand the trade-offs.

        Optional

        Clear local database

        Permanently deletes every indexed package, resource, and creator from the local SQLite file. Your .var files on disk are not touched.

        delete_forever
        This cannot be undone: You will need to re-scan or re-import to rebuild the database. On multi-million-row libraries this takes several minutes. If the path search index was enabled, it will also be wiped.

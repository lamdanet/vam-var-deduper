# Security

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately instead: on the repo's **Security** tab, click **Report a
vulnerability**
([direct link](https://github.com/lamdanet/vam-var-deduper/security/advisories/new)).
Only the maintainer sees the report.

Please include what the problem is, how to reproduce it, and which version
you're on (Settings → About). You'll get a reply as soon as possible. Once a
fix is released, the report can be published as an advisory.

## Supported versions

Only the [latest release](https://github.com/lamdanet/vam-var-deduper/releases/latest)
gets fixes.
